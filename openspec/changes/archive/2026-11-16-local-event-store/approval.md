# 第 2 期人工审批记录

对应任务：`openspec/changes/local-event-store/tasks.md` 1.1
审批范围：`docs/roadmap.md` 第 2 期"人工审批点"要求的三项。

## 1. 删除语义

**结论**：删除按事件 ID 执行，内容（列 + 载荷）在本地移除；被删除事件作为修正目标的引用在 `correction_of` 列与 `payload_json.correctionOf` 两处同时清空；不级联删除其他事件；不复活旧版本；不扩大用户选择范围。

**来源**：用户在提案审查阶段明确选择"改为显式 superseded 标记"方案（对应本变更 design D4/D9），并据此确认"删除链中事件后旧版本不复活"。

**已知边界**：不承诺物理介质擦除，不作用于既有 HA 备份、已导出 NDJSON 或远程接收方数据。

## 2. 迁移失败行为

**结论**：迁移在显式事务内执行，失败即回滚全部 DDL 并保持 `user_version` 不推进；存储进入拒绝写入状态并报告原因；修复迁移实现后可重新打开并成功迁移；不以半迁移 schema 继续提供服务。

**来源**：用户在本变更详细说明中确认该行为及其代价（迁移有 bug 时存储整体不可用直到修复）。

## 3. 备份边界

**结论**：备份使用 SQLite Backup API 生成一致性快照并写入 `<backup>.meta.json`；恢复校验顺序为完整性检查 → 外键检查 → 期望值解析 → 真实读计数比对 → 业务不变量；不承诺物理擦除，不重写既有备份与已导出副本。

**来源**：已在 `docs/technology-stack.md` §5.4 与 `docs/privacy.md` §6 冻结，并在本变更说明中向用户披露；用户未提出异议并同意继续实现。
